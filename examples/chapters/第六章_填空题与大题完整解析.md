# 第六章 · 往返等待

理想化模型：新建 TCP 获取单个极小文档，忽略其他开销，需要两次往返。

### 填空 1
无缓存、新建 TCP、明文 HTTP 请求一个极小文档。仅计两次往返，RTT 为 7 ms，总等待为多少毫秒？（填写数值）______。

**答案：** 14

**解析：** 列出建立连接和请求响应；合计两个 RTT。 结果：14 ms。
