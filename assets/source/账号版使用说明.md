# 计算机网络学习中心 · 账号版

## 本机体验

在项目目录执行 `python account_server.py`（Python 3.11+，无第三方依赖），用浏览器打开 `http://127.0.0.1:8765/`。选「进入本机体验」，设置姓名、学号。此模式的身份属于当前浏览器，通过持久 Cookie 返回同一体验档案；不是微信认证，也不能凭姓名、学号找回账号。共用电脑不适合本机体验。直接打开 HTML 仍然是旧式离线访客。

## 正式微信网站登录

1. 准备可使用网站应用微信登录的开放平台应用。按平台后台要求填写授权回调域，服务回调路径为 `/auth/callback`。此实现是网站扫码流程，不是公众号内静默授权或小程序登录。
2. 管理员在服务器环境设置 `WECHAT_APP_ID`、`WECHAT_APP_SECRET` 和 `STUDY_ORIGIN`（如 `https://study.example.edu`，不要带路径）。不要把密钥写入网页、备份包或聊天。`STUDY_PORT` 默认 8765，`STUDY_DB` 可指定 SQLite 文件的持久路径。
3. 用 HTTPS 反向代理转发到回环地址，保留外部 Host 头，禁用页面缓存；对 `/auth/start` 和 `/auth/callback` 启用速率限制，不记录授权码、Cookie、请求体。不要把整个项目目录作为静态站点公开。
4. 启动 `python account_server.py`。有正式配置后不提供本机体验入口。用真实微信测试首次登录、扫码取消、同一微信从另一台设备重登，以及不同微信账号间的数据隔离。真实扫码必须在部署后验收。

## 保存、恢复与迁移

首次授权后设置姓名和学号。身份以微信网站应用标识和 OpenID 绑定，学号只是展示字段，不会自动合并两个人的数据，也不代表通过学校学籍核验。再次登录不需重新填资料。账号页面可改资料、退出登录。

已同步的数据保存在服务器数据库：收藏、逐题草稿、自评与补练、笔记、模拟卷记录、专项错因、项目与闯关进度及最近一道原题。关闭页面前确认顶部显示「已同步」。多窗口同时写同一类别时，后写入方不会覆盖先写入方；可导出本页备份再刷新。

旧版匿名记录没有身份证明，**不会自动归入任何学生账号**。先在原浏览器、原文件位置打开升级过的离线首页，从「离线访客」导出；再在自己的账号菜单导入。只补空白类别，不覆盖已有类别；最好在新账号开始练习之前迁移。原浏览器数据保留，备份含个人学习内容，请妥善保存。对于按文件隔离存储的浏览器，分别在原填空页和大题页导出。

部署时只授权服务账号访问数据库，定期备份并演练恢复。不要分发 `private-data` 目录。在线账号版、离线访客和本机体验档案相互独立。

## 学习授权与管理员

登录后在首页或个人菜单打开「我的授权」。管理员在 `/admin/licenses` 签发 7、30 或 365 天的码，设备上限可选 1–3 个浏览器；完整码只在签发成功时显示一次。学生在 `/license/activate` 领取，新码可给同一账号续期；新一期重新绑定设备。设备按浏览器 Cookie 计数，不读取硬件编号。过期或被撤销不再允许绑定设备。本次授权功能不含支付，也不会锁定现有题库或删除学习记录。

**首次指定管理员**：由部署者当面核对身份，从该账号「我的授权」页取得账户识别号，在服务器项目目录运行 `python licensing.py grant 账户识别号`。使用与服务相同的 `STUDY_DB`；刷新首页即出现「授权后台」。撤回管理员角色使用 `python licensing.py remove 账户识别号`。没有默认管理员密码，普通账号不能自行授权。
