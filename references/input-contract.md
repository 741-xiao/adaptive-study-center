# 输入、映射、核对

Markdown、TXT、HTML、JSON、CSV 均可作输入。不要求用户改格式。分开提供答案时用章节、题型和原题号关联，不能依靠行号。保留题目原顺序、A1 等附录题号、原公式、表格、单位、解析、易错点、来源文件与页码。有扫描件时先核对 OCR 的负号、上下标和单位。

`python scripts/inspect_bundle.py <文件或目录> ...` 为只读预检。它识别示例 Markdown 的题目标题和答案标记，也接受同结构 TXT、JSON 题目数组及带表头 CSV。HTML、散文、异构表或无法识别的章节会提示人工核对，不表示零道题。运行位置为 Skill 根目录；从其他目录使用脚本绝对路径。

中间记录示意：`{"id":"4-essay-A1","chapter":4,"type":"essay","number":"A1","title":"IP 分片","prompt":"…","answer":"…","steps":[],"explanation":"…","trap":"…","source":"第四章.md · A1","tags":["计算"]}`。模板兼容层依次映射为 `id/ch/type/no/tag/stem/a/why/group`，其中 `type` 为“填空”或“大题”；评分点、来源、步骤等可用额外字段，确保页面实际读取。`courseDocs` 为 `{file,src}` 数组。

从原资料独立清点，按章和题型比对导入后计数、重复键及缺答案。相同题号可跨章或跨题型；同章同型冲突不能覆盖。原题、模型编写的练习和推导答案要有不同标签。不要把知识讲义计为题目。以文本方式渲染输入，内嵌 JSON 时转义 `<`，不执行上传的 HTML 或脚本。
