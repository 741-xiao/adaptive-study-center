# 档案、登录、授权分层

默认本地档案只使用姓名、学号等用户主动填写的信息，按 courseId 和档案 ID 区分进度。明确“仅本浏览器”，不把用户切换当身份验证。离线授权演示仅使用虚构编号及演示数据，显著标明不可用于收费授权。

在线版才提供真正的微信登录、跨设备进度和授权校验。需要后端、HTTPS、已配置的回调域、一次性 state 验证、服务端密钥交换与会话。不要把密钥放进 HTML，不自动部署或配置真实账户。授权码只存哈希。服务端验证学生本人、管理员角色、设备限额、到期和撤销；不通过姓名、学号或前端开关推断管理权限。

学生页保留“我的授权”、激活和续期，展示状态、起止、剩余天数、授权编号、设备名额与绑定。管理员页保留累计签发、有效、即将到期、待激活、七日趋势、状态分布和可筛选清单；提供发码与撤销确认，操作后更新统计。授权失效不删除个人学习记录。验收应覆盖普通用户不能查询他人数据、过期/撤销后操作被拒绝，以及续期后记录仍可恢复。
