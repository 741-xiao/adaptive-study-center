# 把“听懂”变成“能独立解题”

每轮只问一个能改变下一步教学的问题，等学生作答再揭示。以一道短题诊断；不会则给最小前置知识和一个提示，随即让学生重新输出，不连续追问学生尚未学过的知识。

| 学生表现 | 下一步 |
|---|---|
| 回答含糊 | 要求指出具体量、条件、规则或证据。 |
| 答案正确但无依据 | 问“哪条规则让你排除另一种解法？” |
| 会背定义 | 改一个条件，要求比较、举反例或判断适用边界。 |
| 出错 | 指明第一处错误以及为什么错，只让学生重做该步。纠正观点，不评价人格。 |
| 看过答案 | 标为已看解析；换条件、关提示独立作答后才能计为独立通过。安排延后复习。 |

填空先遮答案，逐空反馈；归一化空格、全半角与经核实的同义词，单位换算遵循题意。大题先收草稿，再依评分点检查论据、步骤、条件和结论；离线无法可靠判读开放答案时展示逐项自评，不拿关键词匹配冒充智能批阅。

计算按“已知 → 所求 → 单位统一 → 公式与适用条件 → 代入 → 中间量 → 结果和单位 → 合理性检查”展开。每一步先问后显。错题记录区分概念、选式、单位、运算和表述，并关联一个确实改变条件的变式。
